ReSMap: Recasting Satellite Priors for Robust and Accurate Online HD Map Construction

Hanyang University

*Equal contribution.   †Corresponding author.

  • 53.0 mAP on the nuScenes geographic split at 60 × 30 m, +10.5 over the best prior method
  • 40.9 mAP with all six cameras dropped, above every baseline’s clean-input score
  • 16.1 FPS on a single RTX 4090, faster than the camera-only baseline

1Abstract

Despite recent advances in camera-based online HD map construction, these systems remain susceptible to sensor failures because of their reliance on onboard cameras. Satellite images, in contrast, remain available independently of real-time sensing conditions, since they are cached offline. Existing methods that use satellite images, however, primarily leverage them under nominal conditions, without explicitly addressing them as redundancy when a sensor degrades.

We propose ReSMap, a redundancy-aware camera–satellite fusion framework for robust online HD map construction. A Predict-then-Fuse (PTF) module fuses camera and satellite BEV features using each branch’s own prediction confidence as a per-pixel reliability weight, with no learned router. An Object-Centric Cooperative Multi-modal Query (OCMQ) decoder then propagates this isolation to the query level: each modality cross-attends only to its own BEV, and per-modality updates are merged through a learned per-token gate.

ReSMap achieves state-of-the-art performance on nuScenes across all splits and range settings. More importantly, it also sets a new state of the art under camera-failure scenarios, demonstrating that satellite images serve not only as a strong prior but as practical redundancy for robust online HD mapping.

2Satellite as redundancy

Auxiliary modalities for online mapping are usually chosen for accuracy. LiDAR is still bolted to the same onboard stack that fails, and SD maps carry topology but not lane-level geometry. Satellite tiles are different in one respect that matters for deployment: they are fetched and cached ahead of time, so a hardware fault, an occlusion, or a lost video link cannot take them away.

Existing camera–satellite methods nevertheless fuse the two streams as if both were always trustworthy. Channel concatenation, masked cross-attention, and learned routers all let corrupted camera evidence leak through residual paths, and none of them decides per BEV location how much each modality should contribute, which is exactly what is needed, because the more reliable modality often changes along a single polyline.

ReSMap therefore asks each branch how much it trusts its own reading of every BEV cell, and uses that answer, not a learned comparison, as the fusion weight. The same isolation is carried into the decoder, so that a failing camera cannot contaminate queries that the satellite branch could still explain.

3Method

3.1  Predict-then-Fuse

Per-branch BEV segmentation decoders produce modality-specific logits from Fcam and Fsat. The maximum class-wise sigmoid confidence of each branch becomes a scalar per-pixel reliability map rm, shared across channels and detached from the gradient, so the fusion never learns a modality-comparison weight of its own:

Ffuse(x) = [ rcam(x) Fcam(x) + rsat(x) Fsat(x) ] / [ rcam(x) + rsat(x) + ε ]

We call this the Self-Confidence Gate. The fallback is a closed-form property rather than a learned behaviour: as rcam → 0, the fused feature converges to the satellite feature. Because the gating signal is a prediction confidence and not a raw-image statistic, it also holds up under failures never seen in training, such as cameras zeroed at inference.

3.2  Object-Centric Cooperative Multi-modal Query decoder

A standard DETR-style map decoder undoes this isolation: every query reads from a shared key/value pool that already mixes the three BEVs. The naive fix, one query pool per modality, is worse, because Hungarian matching then routes each ground-truth instance to whichever pool already explains it best, entangling classes with modalities. Dividers become a camera-only skill, boundaries a camera-only skill, crossings a fusion-only skill; when a modality fails, no other branch was ever supervised to take over.

OCMQ keeps a single object-query pool, so the matcher sees one unified set, and creates modality-specific updates only inside each decoder layer:

  1. Modality embedding and intra-group self-attention. The query set is replicated three times, each copy offset by a learnable modality embedding and refined by its own self-attention block.
  2. Per-modality deformable cross-attention. Each conditioned query set attends only to the BEV tensor of its own modality, so BEV-level corruption cannot leak across streams within a layer.
  3. Gated query merging. A per-token softmax gate ωm scores the three updates and merges them back into one query. There is deliberately no residual to the previous-layer query: a residual would let a down-weighted modality re-enter and accumulate over layers.
  4. Inter-object self-attention and refinement. The merged queries exchange information across objects, followed by an FFN, as in a standard decoder layer.

Every class therefore receives gradients from all three modalities, while inference-time contamination is still controlled per token.

    5Results

    Everything below is nuScenes. Models are trained and evaluated on the geographically non-overlapping split, using ego-aligned AID4AD satellite tiles cropped to the BEV region of interest. Except where marked, every baseline is retrained under the same evaluation conditions, following its own paper’s schedule.

    5.1  Clean conditions

    At 60 × 30 m, ReSMap reaches 53.0 mAP with temporal modelling and 47.0 without, in 24 epochs, ahead of the camera-only MapTracker by 12.7 mAP, the LiDAR-fused DAMap by 13.6, and the SD-fused PriorDrive by 10.5. At 100 × 50 m, where camera evidence thins out with distance, the margin widens to 18.5 / 24.7 / 32.2 mAP, and the temporal variant is best on all three classes. The satellite branch costs little at inference: 16.1 FPS is faster than the camera-only baseline and roughly twice the LiDAR- and SD-fused models.

    5.2  Camera failure

    Robustness is measured by zeroing the front camera, the three front cameras, and all six cameras at inference time, replacing each dropped view with a blackout image.

    The non-temporal ReSMap degrades by 4.0%, 7.7%, and 13.0%, the smallest drop at every level. The all-camera case isolates the redundancy claim most clearly: with no camera evidence at all, ReSMap still returns 40.9 mAP, higher than the clean-input score of every baseline in the table, while MapTracker collapses by 99.8% and even the LiDAR-fused DAMap loses a quarter of its accuracy.

    The temporal variant is the stronger model on clean input but the weaker one under severe failure. This is not a contradiction: temporal aggregation is applied to the camera BEV, so corrupted frames enter the memory queue and keep contaminating the fused stream for several frames. We diagnose this directly in §7.

    5.3  Corrupted satellite tiles

    Satellite tiles can be stale or misaligned in practice, through GPS/INS drift or latency in the localisation stack. We inject two such corruptions at inference with probability p = 0.2 per sample.

    6Ablations

    Both ablations are run on the geographically non-overlapping split. In (a) the decoder is fixed to the full OCMQ; in (b) the fusion is fixed to PTF, so that Fcam, Fsat, and Ffuse are identical across rows.

    Cross-attention fusion is the least robust of the four: it reaches 45.5 clean mIoU and essentially nothing under all-camera drop, because corrupted queries still reach the fused representation through residual paths. ConvFuser and CIT + DDF are stable on clean input but neither suppresses the unreliable branch explicitly. PTF is best in every column.

    On the decoder side, per-modality cross-attention restores BEV-level isolation and lifts Front-1, but barely moves the all-camera case; adding modality embeddings helps there and hurts elsewhere, because the uniform mean still drags clean tokens toward the weakest modality. Only the learned gate is best in all three columns.

    7Analysis

    7.1  Where the evidence goes

    7.2  Why the non-temporal variant survives severe failure

    Running both variants over the full validation split (5 981 frames) and restricting the statistics to active cells makes the mechanism explicit. Under all-camera drop, the temporal rcam falls from 0.751 to 0.166 (−77.9% relative) while the non-temporal one falls from 0.686 to 0.278 (−59.5%). More tellingly, the temporal fused stream is contaminated rather than redirected: rfuse drops 35.6% and the feature norm ‖Ffuse‖ contracts 19.1%, against 18.3% and 6.2% for the non-temporal variant.

    The satellite reliability is essentially unchanged across all six conditions (0.473 vs. 0.456), so the difference is not a satellite-side artefact. Temporal aggregation is applied only to the camera BEV, so corrupted evidence accumulates in the BEV history and enters Ffuse before OCMQ ever sees it, and a per-token gate cannot repair a fused BEV whose evidence is already corrupted.

    7.3  Class–modality entanglement

    Trained with independent per-modality query pools, each branch specialises: the camera branch is strongest on lane dividers and boundaries, the satellite branch on pedestrian crossings, and the fused branch carries the overall mAP almost entirely through APp. That model loses 15.9 mAP when the three front cameras are dropped, and its largest single-class drop (APb, −28.9) is precisely the class the camera branch had monopolised. No other branch was ever supervised on it, so nothing can compensate, even though the PTF gate has already reallocated its weight. This is the observation that motivates OCMQ’s single shared pool.
