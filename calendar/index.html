우리 달력둘이 같이 쓰는 달력

일정은 비공개 저장소 dehsurc/calendar_private에만 저장돼요. 이 기기에서 처음 한 번만 GitHub 토큰을 입력하면 돼요.

Token

토큰은 어떻게 만들어요?
  1. GitHub → Settings → Developer settings → Personal access tokens로 들어가요.
  2. 저장소 주인(dehsurc): Fine-grained tokens에서 Repository access를 calendar_private만으로 고르고, Permissions → Contents를 Read and write로 설정해요.
  3. 초대받은 사람: 초대를 수락한 뒤 Tokens (classic)에서 repo 권한으로 만들어요. Fine-grained 토큰은 다른 사람 저장소에는 쓸 수 없어요.
  4. 만료되면 여기서 새 토큰을 다시 입력하면 돼요.
